### 웹용 이미지 최적화

일반 이미지의 긴 변은 최대 1600픽셀, 파노라마는 최대 2400픽셀로 제한하고 원본보다 확대하지 않았습니다. JPEG 품질은 85, PNG는 크기 조정 후 무손실 인코딩입니다. research-points.png 원본만 research-points.jpg로 바꿨으며 다른 파일명은 유지했습니다. lab-3d.png는 원본 내부 인코딩이 JPEG이고 재인코딩 시 오히려 커져 원본 바이트를 유지했습니다. 인물이나 장면을 크롭하거나 색보정하지 않았습니다. 상장 4장·특허 미리보기는 해시 비교로 미수정을 확인했습니다. 2026-10-16 최적화 직후 배포 이미지 전체는 4,072,079바이트(3.88MiB)입니다. 근거와 원본·최적화 SHA256은 ../../evidence/optimization.json에 기록했습니다.
