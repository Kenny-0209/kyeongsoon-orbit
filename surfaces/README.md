# 현장 벽·바닥 메시

잠실·마곡1·마곡2에서 직접 복원한 기존 벽면과 바닥을 웹에서 전환해 보기 위한 폴더입니다. 각 현장의 `wall.glb`와 `floor.glb` 및 크기·면 수·검증 해시를 담은 `index.json`이 있습니다.

모든 원본 삼각형을 보존하고 좌표와 RGB가 정확히 같은 꼭짓점만 합쳤습니다. 각 현장의 MVS 표시 좌표계와 공통 프레임을 사용하므로 SfM·MVS·복셀과 전환할 때 같은 위치와 크기를 유지합니다. 색은 원본의 객체 분류색이며 사진 텍스처가 아닙니다. 원본 경로와 좌표 변환의 내부 정보는 공개 파일에 포함하지 않습니다.
