# ORBIT · 김경순

연구, 게임, 소프트웨어, 기록과 성과를 탐색하는 개인 3D 홈페이지입니다.

## GitHub Pages

정적 파일로 구성되어 빌드나 서버 설치가 필요하지 않습니다. 저장소 설정의 **Pages → Deploy from a branch → main → /(root)**로 게시합니다. 파일 경로는 프로젝트 하위 경로에서 동작하도록 상대 경로를 사용합니다.

## 구성

- `index.html`, `style.css`, `refine.css`: 화면과 반응형 스타일
- `app.js`, `content.js`, `verified.json`: 3D 장면, 작업 목록, 공개 소개 자료
- `assets/`: 홈페이지에 표시하는 이미지와 지도. 이미지의 재사용 권한은 각 권리자에게 있습니다.
- `vendor/`: Three.js, D3.js와 원본 라이선스
- `.nojekyll`: GitHub Pages에서 정적 파일을 그대로 제공하는 설정

원본 홈페이지 게시 커밋: `6b1cc826ace1c56cdac5edffa7d9b303bb904a76`.
비공개 증빙과 운영 자료는 포함하지 않습니다. 일부 외부 개인 서비스는 별도 로그인이 필요할 수 있습니다.
