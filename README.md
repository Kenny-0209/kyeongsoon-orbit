# ORBIT · 김경순

[홈페이지 열기](https://kenny-0209.github.io/kyeongsoon-orbit/)

연구실 활동, 연구 활동, 개인 작업의 세 가지 테마를 탐색하는 개인 3D 홈페이지입니다. 실제 공간 복원 점군, 장비 모형과 부품 설명, 연구 기록을 포함합니다.

## 현장 사진의 동바리

연구 활동의 동바리는 실내 현장 파노라마를 참고한 개별 길이 조절식 서포트입니다. 상하 받침판과 중간 조절 부위가 있으며 각 기둥이 콘크리트 천장 슬래브를 받칩니다. 소개를 위한 개념 모형이며 실측 모델이나 구조 성능 자료를 뜻하지 않습니다. 상세 화면의 작은 그림도 같은 형태로 맞췄습니다.

## 구성

- `index.html`, `style.css`, `spatial.css`: 반응형 홈페이지와 테마 선택
- `entry.js`, `stage.js`, `gallery.js`, `details.js`: 3D 전시, 모형 상호작용, 상세 기록
- `gear-pc.js`, `gear-input.js`: 장비와 주변기기 모형
- `content.js`, `verified.json`: 공개 소개와 연구 기록
- `assets/`: 공개 사진과 지도. 이미지 재사용 권한은 각 권리자에게 있습니다.
- `clouds/`: 실제 연구 결과의 웹용 점군·복셀 표본
- `models/`: 내려받을 수 있는 GLB 장비 모형과 목록
- `vendor/`: Three.js, D3와 각 원본 라이선스
- `app.js`, `refine.css`: 이전 화면의 참조 소스

정적 사이트로 빌드가 필요하지 않습니다. GitHub Pages는 `main`, `/(root)`를 사용하고 `.nojekyll`로 파일을 그대로 제공합니다. 경로는 프로젝트 하위 경로에서 동작하는 상대 경로입니다.
