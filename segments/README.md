# 객체 세그멘테이션 표시 자산

2026년 10월 16일 ORBIT의 객체 세그멘테이션 항목에서 하나의 실제 건설 현장 파노라마를 유지하고, 동바리·벽면·창문·바닥·천장 결과를 차례로 강조하도록 만든 폴더입니다. 다른 현장·다른 프레임의 결과를 섞지 않았습니다.

## 파일 구성

- index.json: 원본 이미지, 전체 픽셀 크기, 마스크 5종의 id·한글 이름·파일·대표색·확인 한계를 담은 표시용 manifest입니다. 파일 경로는 웹 루트 기준입니다.
- panorama.jpg: 기존 연구 입력 frame_000150.jpg의 전체 프레임 축소본입니다.
- shoring.png: 동바리, 분홍색.
- wall.png: 벽면, 청록색.
- window.png: 창문, 노란색.
- floor.png: 바닥, 보라색.
- ceiling.png: 천장, 파란색.

원본과 다섯 PNG는 모두 2048×1024픽셀, 가로세로 2:1입니다. 좌표 원점은 좌상단이며 X는 오른쪽, Y는 아래입니다. 이미지의 전체 사각형이 UV [0,0]~[1,1]에 대응합니다. 5760×2880 원본에서 전체 프레임 비율 축소만 했으며 크롭·회전·경도 이동·투영 변경을 하지 않았습니다. 각 레이어의 표시 사각형을 정확히 같게 두고 object-fit을 적용한다면 모든 레이어를 동일한 contain 사각형에 맞춰야 합니다.

## 실제 결과와 표시 경계의 구분

기존 캡스톤 발표 자료에는 동일 frame_000150에 대응하는 클래스별 RGB 추출본이 있습니다. 이 폴더는 그 실제 결과의 검정 배경을 제거하여 표시용 alpha를 복구한 것이며, 새로운 모델 추론이나 수동 영역 작성이 아닙니다. 원래의 이진 마스크 자체는 이번 확인 범위에서 확보하지 못했습니다. 따라서 JPEG 경계와 매우 어두운 픽셀에는 원래 이진 마스크와 차이가 있을 수 있습니다. 검출되지 않은 물체를 임의로 추가하거나 빠진 부분을 채우지 않았습니다.

기본 채움 alpha는 140/255(약0.55), 원래 footprint 안쪽 1출력픽셀 경계는205/255입니다. 바깥쪽으로 영역을 팽창시키지 않았습니다. 단색 강조용 오버레이이므로 RGB 사진을 다시 겹쳤을 때 강조가 보이지 않는 문제를 피합니다.

동바리는 기존 Pipe 프롬프트 추출본의 수직 가설 지지대입니다. 상단 받침과 수직 기둥이 실제 사진에서 확인되며 당시 연구 메모에서 Pipe를 temporary support pole로 변경하고 동바리로 부르는 기록을 확인했습니다. 설비 배관을 임의로 동바리라고 바꾼 것이 아닙니다.

원본·기존 RGB 추출본·SHA256·정합 수치·클래스별 alpha coverage·복구 코드는 배포 폴더 밖 ../../evidence/segments에 보관합니다. source RGB는 그대로 보존했고 기존 연구 파일은 수정하지 않았습니다.
